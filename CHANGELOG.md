## 0.1.0

- Initial release of Serverpod DevTools (`serverpod_dev_tools`).
- **ER Schema Visualizer**: Interactive 2D canvas with Crow's foot notation, automatic relation resolution, and YAML model viewer.
- **Live Database DataGrid**: Paginated PostgreSQL table browser with column sorting, search, and type-aware formatting.
- **Endpoint Explorer & RPC Caller**: Interactive endpoint caller with typed argument inputs and response viewer.
- **HTTP Workspace Suite**: RFC 7230 `.http` file parser, variable substitution, and request synchronizer.
- **Dependency-Ordered Mock Data Generator**: Topological DAG sorter ensuring foreign-key parent-child integrity when generating mock rows.
- **Dual-Mode Connectivity**: Seamless switching between Dart VM Service RPC and HTTP REST fallback for companion Flutter apps and web browsers.
